# T'Nature — site d'aperçu

Copie de travail du site de **T'Nature** (gîte et maison d'hôtes, 1 rue de
l'Église, 39210 Château-Chalon), mise en ligne pour relecture par la cliente.

**Ce n'est pas le site public.** Les trois pages portent une balise
`noindex, nofollow` : cette adresse ne doit jamais être référencée à la place
du vrai domaine.

Le contenu est généré depuis les sources du projet — ne rien corriger ici, tout
serait écrasé au déploiement suivant.
